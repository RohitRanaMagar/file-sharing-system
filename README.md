# File Sharing System

Final project for 8th sem BIT Gandaki University

## Project Overview
This is a modern file sharing system built with React and Vite.

## Setup and Installation

### Prerequisites
- Node.js (v18 or higher recommended)
- npm or yarn

### Steps
1. Clone the repository
2. Install dependencies:
   ```bash
   npm install
   ```
3. Start the development server:
   ```bash
   npm run dev
   ```

## Vite Template Info
